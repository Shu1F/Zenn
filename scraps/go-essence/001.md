## Goの基本文法

- 静的
- GC（Garbage Collector）がある
- 三項演算子はない
- 継承はない
- 例外はない
- セミコロンを使用しない

### 変数宣言

- 同じ変数で異なる型を代入することはできない

```go
var n int
n = 1
n = "hoge" // コンパイルエラー
```

- 同じ変数名で再度宣言することもできない

```go
var n int
n = 1

var n string // コンパイルエラー
n = "hoge"
```

- 以下のような場合は型をキャストする必要がある

```go
x := 1 // := することで型を省略して宣言することが可能
y := 1.2

n := 1 + (x + 2) * int(y) // yはfloat64型でxはint型なので型をキャストする
```

### 定数宣言

- var の時とは反対にconstの時は以下のように書くことが可能

```go
const n = 1
y := 1.2 + n // 型キャストの必要がない
```

### iota（列挙）

```go
const (
    A = iota
    B
    C
)

fmt.Println(A, B, C) // 0 1 2
```

- 実際アプリケーションでどのように使うのか？

- ToDoアプリを例にとる

**boolean型でのステータス管理**

```go
type TodoTask struct {
    ID        int
    Title     string
    Completed bool
}

task := TodoTask{
    ID:        1,
    Title:     "Go言語を学ぶ",
    Completed: false,
}

if task.Completed {
    fmt.Println("完了済み")
} else {
    fmt.Println("未完了")
}
```

**iotaを使ったステータス管理**

```go
type TaskStatus int

const (
    Todo TaskStatus = iota
    InProgress
    Done
)

type Task struct {
    ID     int
    Title  string
    Status TaskStatus
}

task := Task{
    ID:     1,
    Title:  "Goを勉強する",
    Status: InProgress,
}

switch task.Status {
case Todo:
    fmt.Println("未着手")
case InProgress:
    fmt.Println("進行中")
case Done:
    fmt.Println("完了")
}
```
