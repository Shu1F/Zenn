## コンストラクタ

`User` 構造体を考えてみる。

```go
type User struct {
    Name  string
    Age   int
    Email string
}

func NewUser(name, email string, age int) (*User, error) {
    if name == "" {
        return nil, errors.New("name cannot be empty")
    }

    // 他にも検証を書く

    return &User{
        Name:  name,
        Age:   age,
        Email: email,
    }, nil
}
```

構造体をそのまま生成するより、初期化前に検証を行えることが利点。
